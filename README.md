# Odin Recipes

A simple recipe website built as part of The Odin Project curriculum to practice foundational HTML and professional version control workflows.

## Features

- **Home Page (`index.html`):** Features a clean semantic navigation menu linking to regional Middle Eastern dishes.
- **Recipe Sub-pages:** Includes detailed ingredient lists, step-by-step preparation guides, and high-quality imagery for:
  - Egyptian Koshari
  - Saudi Chicken Kabsa
  - Palestinian Musakhan
